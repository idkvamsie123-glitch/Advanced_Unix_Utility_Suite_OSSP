Child process (PID: 4013) replaces its text & data segment with the echo binary program.

Pipe Mechanism
pipefd[0] = Read End | pipefd[1] = Write End.
Data flows strictly in FIFO order through kernel ring memory without touching the physical disk.

Why sig_atomic_t?
Signals interrupt asynchronous execution at arbitrary instructions. Variables modified inside signal handlers must be declared volatile sig_atomic_t to guarantee atomic read/write.
